# Install Opportunity research

Copy `SKILL.md` and the entire `references/` directory from the same repository commit into `opportunity-research/` under your client's skill directory. For clients that discover project-local skills in `.agents/skills/`, the destination is `.agents/skills/opportunity-research/` in the project where you want to run the research. Refresh the client's skill list or start a new session after copying.

Research output goes into the target project's `phases/` directory. The [source guide](../references/source-guide.md) lists public sources and paths for optional local copies under `ref/` in that project.
